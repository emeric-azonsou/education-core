# Contributing

1. Create an issue describing the problem or proposal.
2. Fork the repository and create a focused branch.
3. Add or update tests for behaviour changes.
4. Run `npm run verify` before opening a pull request; this compiles the package,
   runs the unit and CLI suites, and checks the publishable package contents.
5. Explain the educational use case and compatibility impact in the pull request.

Please do not include student data, credentials, API keys or proprietary curriculum content in issues or pull requests.
