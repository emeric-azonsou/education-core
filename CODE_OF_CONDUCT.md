# Code of Conduct

ClasseKit Education Core is a collaborative project. We want participation
to be welcoming, practical and respectful.

## Our standards

Participants are expected to:

- communicate with respect and assume good intent;
- give feedback about the work, not the person;
- explain technical disagreement with evidence and curiosity;
- welcome people with different backgrounds, languages and experience levels;
- protect privacy and keep examples synthetic.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate disruption, publishing private information, and sharing student
data, credentials or other confidential material.

## Enforcement

Report a concern privately to the repository maintainer through the GitHub
profile. Reports will be handled confidentially as far as practical. Project
maintainers may remove comments or content, close issues or pull requests, or
restrict participation when necessary to keep the project safe and useful.

This document is adapted from the principles of the Contributor Covenant.
